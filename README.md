# Laravel Quiz Application

A simple multiple-choice quiz application built with Laravel, PHP,
Eloquent ORM, Blade, and SQLite/MySQL.

## Features

- View available quizzes
- View quiz details
- Start a quiz
- Answer multiple-choice questions
- Submit quiz answers
- Calculate score
- Store quiz attempts
- Review submitted answers
- Show correct answers
- Show unanswered questions
- Anonymous quiz attempts
- Responsive Bootstrap UI
- Laravel route model binding
- CSRF protection
- Request validation
- Database transactions
- Seeder with sample quizzes

## Requirements

- PHP
- Composer
- SQLite or MySQL
- Laravel 13.x-compatible PHP environment

## Installation

### 1. Create or download the Laravel project

If starting from scratch:

```bash
composer create-project laravel/laravel quiz-app
cd quiz-app
```
